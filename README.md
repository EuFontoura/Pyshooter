
# Pyshooter

Uma recriação do clássico Endless War 3, originalmente desenvolvido em Flash para navegadores. Este projeto surgiu como parte de um trabalho acadêmico, cujo objetivo era desenvolver um jogo 2D utilizando Python.

A escolha do Endless War 3 foi motivada pela variedade de mecânicas e conceitos presentes no jogo, proporcionando uma excelente oportunidade de estudo e prática em áreas como inteligência artificial básica, movimentação de personagens, detecção de colisões, efeitos sonoros e efeitos visuais.

Além de reproduzir a experiência do jogo original, o projeto serviu como uma forma de explorar o desenvolvimento de jogos com Python, utilizando principalmente Pygame, e aprofundar conhecimentos em programação orientada a objetos e arquitetura de jogos.
